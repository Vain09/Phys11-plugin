# PhysBone Studio (plugin downloads)

Install in game:
1. `/xlsettings` > **Experimental** > **Custom Plugin Repositories**: add
   `https://raw.githubusercontent.com/Vain09/Phys11-plugin/main/repo.json`, tick it, **Save**.
2. `/xlplugins`, search **PhysBone Studio**, install, open with `/physbone`.

Needs Penumbra. Exporting newly drawn bones also needs XAT (XATHavokInterop.exe), set in `/physstudio settings`.
